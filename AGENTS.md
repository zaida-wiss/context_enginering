# AGENTS.md — AI entrypoint

This repository is the source of truth for AI-assisted work on Avanza Team 1.

## Start here

1. Read `README.md` from the same branch/tag/commit ref you were given.
2. Follow the route in that README for the current task.
3. Treat linked authority files as the source of rules; do not duplicate or invent policy here.
4. Keep every internal `context_enginering` read on the same ref for the entire task.
5. If a mandatory file is missing on that ref, stop and report it. Never fall back to another branch.
6. Re-check live source/tool availability for each new task. Do not claim a source was verified unless it was actually read in that task.
7. Investigate before answering: open referenced files and current project sources before making repository-specific claims.

## Change discipline

- Make the smallest coherent change.
- Put a rule in the authority file that owns that rule category; do not create competing policy documents.
- Prefer links/maps over copying large instruction blocks into always-loaded context.
- For risky or broad changes, use a branch and pull request rather than writing directly to the leading branch.
- Validate affected invariants and existing audits before proposing merge.
- Keep human judgment at decision points: AI may analyze and propose, but must distinguish verified facts from inference.
