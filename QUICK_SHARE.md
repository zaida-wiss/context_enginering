## 💬 Vanliga Frågor Att Ställa Till AI

Efter att du delat länkarna, kan du fråga:

```
"Läs dessa filer och svara på:"
- Vad är projektets problem?
- Vilka är MVP-features?
- Vilka är kodstandarder?
- Vilka är arkitektur-beslut?
- Vad är status denna vecka?
```

```
"Baserat på repot: Vad bör vi fokusera på denna vecka?"
```

```
"Vilka risker finns? (Läs RISKS från Google Sheets)"
```

```
"Verifiera consistency mellan git, GitHub Project Board, och risker"
```
