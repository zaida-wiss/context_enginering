# 🤖 AI Guides - How to Use

**Denna mapp innehåller instruktioner för AI om hur den ska fungera i detta projekt.**

Använd dessa filer när du:
- ❓ Inte vet vad du kan be AI om → `WHAT_CAN_I_HELP_WITH.md`
- 🤖 Vill köra ett möte → `AI_TEAMLEADER.md` + relevant möte-fil
- ✅ Vill verifiera konsistens → `VERIFICATION_SYSTEM.md`
- 📋 Vill skapa issues → `BACKLOG_TEMPLATE.md`
- 🎓 Vill förstå pedagogisk vägledning → `PEDAGOGICAL_GUIDANCE.md`
- 🔒 Vill förstå accessibility & security → `ACCESSIBILITY_AND_SECURITY.md`
- 🎨 Frontend-specifika frågor → `FRONTEND_AI_INSTRUCTIONS.md`

## 🎯 Quick Start

**Vilken möte vill du köra?**

```
1. Kopiera: AI_TEAMLEADER.md
2. Kopiera: MEETING_THURSDAY.md eller MEETING_MONDAY.md
3. Kopiera: Git log + GitHub Project Board status
4. Säg: "Kör mötet!"
```

**Vet du inte vad du ska be AI om?**

```
1. Läs: WHAT_CAN_I_HELP_WITH.md
2. Välja en uppgift
3. Be AI om hjälp
```

**Vill du verifiera att allt är konsistent?**

```
1. Läs: VERIFICATION_SYSTEM.md
2. Copy-pasta: git log + Project Board + Risker
3. Säg: "Verifiera consistency"
```
