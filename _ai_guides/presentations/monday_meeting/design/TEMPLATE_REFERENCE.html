🎯 Nyckelprinciper för NPF-vänlighet

Symbol + Färg + Text

Information ska alltid presenteras via TRIO — aldrig bara text, aldrig bara färg.

✅ RÄTT:
🟢 MERGED Denna vecka

Läsare ser: symbol (🟢) + färg (grön bakgrund) + text ("MERGED")
❌ FEL:
Endast text: "Issues merged denna vecka"

Dyslektiker måste läsa texten. Ingen visuell signal.
Radhöjd & Whitespace

Måste vara stor för läsbarhet och för att ge hjärnan tid att bearbeta.

✅ RÄTT:
24px+ radhöjd mellan element
12px padding per cell
8px margin mellan sektioner

Mycket luft runt text gör det lätt att fokusera.
❌ FEL:
16px radhöjd i tabeller
Kompakt layout
Text trängt tillsammans

Svårt att scanna. Stimulerande för ADHD/autism.
Font-storlekar

Text måste vara stor, särskilt för tabell-data.

  • 14pt BOLD — Sektion-headers ("MERGED DENNA VECKA")
  • 13pt regular — Issue-data, namn, status
  • 12pt — Meta-text (datum, branch-namn)
  • ALDRIG <10pt — Otillåtet för NPF
Visuell gruppering

Färgade sektioner hjälper hjärnan att organisera information.

✅
MERGED
◐
PÅGÅR
⏳
REVIEW

Varje sektion har egen färg + symbol. Läsaren VET omedelbar vad det är utan att läsa texten.

Rundade hörn

6-8px corner-radius på alla boxar — mjukare, mindre stressande visuellt.

🚫 FÖRBJUDNA PATTERNS (NPF-VIOLATIONS):

❌ Tabeller med >3 kolumner (lätt att tappa raden när man scannar)
❌ Text <13pt i tabeller
❌ Radhöjd <24px
❌ Färg UTAN symbol + text (måste vara trio)
❌ >5 objekt per sektion utan gruppering
❌ Rundade hörn <6px (ser oprofessionellt ut och är mindre effektivt)
Sammanfattning: NPF-vänlig design är INTE bara om större text. Det handlar om att presentera information på ett sätt som barnets lätt kan procesera — med Symbol + Färg + Text tillsammans, mycket whitespace, och visuell gruppering. Läs ACCESSIBILITY_NEURODIVERSITY.md för fullständig filosofi.
