📊 Presentation Template Reference

Denna sida visar EXAKT hur slidorna ska se ut. Använd den som referens när du bygger presentationen i PowerPoint/Slides.

⚠️ KRITISKT: DESIGN-REFERENS ONLY — ALDRIG ANVÄND EXEMPEL-DATA

Denna fil visar HOW-DESIGN (färger, fonts, spacing), INTE WHAT-DATA.

✅ ANVÄND denna för:
1. Se RGB-värden (grön 76,175,80 | orange 255,152,0)
2. Kopiera font-storlekar (14pt bold headers, 13pt content)
3. Se spacing (24px radhöjd, 12px padding, 6-8px corner-radius)

❌ ANVÄND ALDRIG denna för:
1. Exempel-data (#95, #87, etc) — dessa är FAKE
2. Att bygga presentation utan LIVE GitHub-data
3. Att kopiera tabeller direkt — måste fetcha LIVE data

REGEL: All DATA i faktisk presentation MÅSTE hämtas LIVE från GitHub när presentationen byggas. Aldrig från snapshot, aldrig från exempel.

🎯 Key Design Points:
  • Team-märking: Varje rad visar team-badge (🔵 Frontend, 🟢 Backend, 🟣 Native)
  • Assignad-status: Visar namn om assignad; gul highlight + 🔄 UNASSIGNED om ingen är tilldelad arbetet
  • Färgade sektion-headers: 🟢 Grön för Merged, 🟡 Orange för Pågår & Review
  • Statussymboler: ✓ (DONE), ◐ (PÅG), ⏳ (REVIEW) - symbolen kommer före texten
  • Rundade hörn: 6-8px på alla textboxar och sektion-headers
  • Radhöjd: Minst 24px för varje tabellrad (läsbar från mötesbord)
  • Font-storlekar: 14pt bold för headers, 13pt regular för innehål, 12pt för meta-text
  • Whitespace: 12px padding, 8px mellan sektioner
  • Kontrast: Vit text på färgad bakgrund (4.5:1 minimum)
