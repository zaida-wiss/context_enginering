Design Principles:
• Dark navy theme (#0F1830) on all slides
• Team colors (teal #2DD4BF / hot pink #FF4FA3 / purple #A855F7) on borders + badges only
• Light slate border (#CBD5E1) for cross-team work (neutral multi-team)
• Status shown via symbol + text (✅ Merged, ◐ Pågår), not color
• Large whitespace for accessibility
• Max 12 cards per slide = auto-split to ①A.2, ①B.2, ①C.2 if needed
